About the project

About Power Watch

Power Watch is a small, three-page demonstration website built for a university web development exercise. It's designed to show how HTML, CSS and JavaScript work together to build a simple, consistently styled, interactive site.

What this site covers

Placeholder project description.

  • A consistent top navigation with an active-page indicator across all three pages.
  • Home page content on Australian household appliance energy use, with an accordion-style FAQ.
  • An interactive appliance energy calculator on the Televisions page, built with vanilla JavaScript.
  • A single external stylesheet applied consistently across every page.

A note on the figures

Appliance wattages, percentages and other statistics shown on this site are illustrative placeholders created for this exercise. They are not verified data and shouldn't be relied on for real-world decisions.
